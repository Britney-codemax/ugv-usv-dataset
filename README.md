# UGV–USV Detection Dataset
# 无人车与无人艇目标检测数据集

面向无人车（UGV）与无人艇（USV）的两类目标检测数据集，提供 YOLO 格式的矩形框标注及图像增广样本，供项目组开展模型训练和实验。
当前仓库用于项目组共享，整理了已有的开源数据集、零散的无人车无人艇的照片以及上海交通大学购买的无人车和无人艇我们自主拍摄的图片


## 数据规模

| 项目 | 数量 |
|---|---:|
| 原始图片 | 480 张 |
| 增广图片 | 1,920 张 |
| 图片总数 | 2,400 张 |
| 标签文件 | 2,400 份 |
| 原图中的标注框 | 540 个 |
| 含增广样本的标注框总数 | 2,700 个 |
| 目标类别 | 2 类 |

增广图片由原始图片派生，不代表额外采集的独立样本。
标注框数量也不代表现实中互不重复的设备数量。

## 类别定义

| 类别编号 | 类别 | 英文名称 | 标注框数量（含增广） |
|---|---|---|---:|
| 0 | 无人车 | Unmanned Ground Vehicle / UGV | 1,385 |
| 1 | 无人艇 | Unmanned Surface Vehicle / USV | 1,315 |

类别编号固定为：0＝无人车，1＝无人艇。

## 文件组织

完整数据解压后包含：

    imgs/
      1.jpg
      ...
    labels/
      1.txt
      ...

图片与标签文件同名，一一对应。编号保留清理后的空缺，无须重新编号。

每个目标占标签文件中的一行：

    class_id x_center y_center width height

坐标均按对应图片的宽、高归一化至 0～1。
一张图片包含多个目标时，标签文件包含多行。

## 数据增广

每张原图生成四张增广图片：

| 操作 | 方法 | 标注处理 |
|---|---|---|
| 水平翻转 | 左右镜像 | 同步翻转横坐标 |
| 高斯噪声 | 标准差 5，像素尺度 0～255 | 坐标不变 |
| 曝光调整 | 亮度乘以 0.8 或 1.2 | 坐标不变 |
| 小角度旋转 | 随机正负 3°～8°，扩展画布并填充灰色 | 同步变换框，再计算外接矩形 |

旋转后的矩形框可能包含更多背景。

## 标注检查

数据经过带框视觉复核，并修正了已发现的类别混淆、非目标误标、
漏标和边界不完整等问题。

本地结构检查结果：
- 图片与标签数量一致，文件配对完整；
- 标签使用有效的类别编号；
- 未发现空标签、无效尺寸或越界坐标。

视觉复核仍可能存在主观边界差异，不能代替对每台设备无人能力的来源认证。

## 下载与使用

Hash： E9DA074B0E9940D792F4C21506D2E7A6D0223492A8A81AECC49C8C61F5D61A5A
DOI:10.5281/zenodo.23794441
github中仅展示sample，完整数据集上传至Zenodo

当前未提供固定的训练集、验证集和测试集划分。
划分时，同一原图及其全部增广版本必须进入同一集合；
连续拍摄、同场景或高度相似的原图也应尽量归入同组，降低数据泄漏风险。

建议先划分原始图片，再将增广样本用于训练集。
验证集和测试集优先使用未增广的原图。

训练前，请按所用框架的要求配置图片路径和标签目录。

## 当前限制

- 2,400 张图片中包含 1,920 张增广图片；
- 当前尚无基于该数据集的统一模型性能基准；
- 不应据此宣称准确率、mAP 或泛化能力已有提升；
- 图片来源和再分发许可尚未完成统一核对。
